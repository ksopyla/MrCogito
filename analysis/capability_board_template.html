    The ladder: how far up does each model get?

    Levels from the hardest (top) to the simplest (bottom); each level builds on the one below. A cell counts the level's ready tasks (frozen recipe) the model passes: at least 75 %, median over seeds 0–2, from scratch, on the written recipe. Green = all, amber = some, red = none; a dot = no matching result yet. Tasks still being calibrated are listed in their level but never counted.

    Rules: capability checks spec · levels and tasks: capability_tasks.py

    Tasks by level

    Every task of the ladder, hardest level first. The number is the task's own score in percent at the training length, median over seeds 0–2; the small line is the same model reading a 128k book. A solid outline is a pass on a result that matches the task definition; hatched cells come from an older protocol and do not count; greyed rows are still calibrating. Reference is the model that proves the task learnable: dense when it passes (the ceiling), otherwise the best model that learns it from scratch. Hover any name or number.

    Length charts: does it hold up as the book grows?

    Every ready task with a length ladder, hardest level first. Each model trains at the task's length, then reads longer books with no more training. Ladders record the first answer letter (also on tasks scored on the picked candidate), median over seeds, only where every seed was read. The dashed line is the 75 % pass mark. Dashed cards come from an older protocol.

    Flawed tasks

    Each has a known shortcut, so a high score does not show the capability it is named after. Kept so nobody reuses them; past reports that cite them carry a re-scoring note.
