E31 wiring: every layer, every token, on a 17-token example

Yes, there are two paths running in parallel from the same token embeddings. The memory path (purple, below the embeddings) writes latents from each window of the book. The main path (blue, above) is an ordinary causal language model over the whole row. They meet at one place: the global-read layer, where the memory slots are appended to that layer's keys and values. There is no separate "decoding stage". The answer is produced by the main path's top layers, like any next-token prediction. Companion page: E31 architecture & checklist.

How to use this page

  1. Click any state (a cell). Orange shows everything it depends on, all the way down to token embeddings, and lines show its direct inputs.
  2. Start with the answer prediction at position 13 (green, top row). Its dependencies run through the global read into the memory slots, then down to the fact's tokens. That's the whole route the fact takes.
  3. Switch Writer → E30 as built and click the slot row: the writer reads the main path's first local layer, where value letter v3 can't see the keymark (no ●).
  4. Switch Setting → text: no QUERY, every position predicts the next token and reads the slots of windows that have already closed, so nothing is a dead end.
  5. Step through the forward pass to see the order in which layers compute.
