Lookup accuracy vs book length

Dashed line = pass line (75 %). The baseline memory learns an absolute-position read: trained at length L it reaches ≈ 2L. The length-invariant memory (no window-start address, slot keys rotated at the question) transfers across length and needs only one short 8k stage.

Chain (4 hops): full attention fails at 2×, the length-invariant memory transfers 16×

Dense and the baseline memory learn a position shortcut tied to book length: chain works only at the training length. The length-invariant memory (started from its lookup weights, so content addressing is already learned) keeps 92 % at 16k and 80 % at 32k after training only at 2k, and 93 % at 64k / 82 % at 128k after one 8k stage. From scratch it did not take off.

Honest caveats

  • The 2k → 8k → 16k curriculum result replicates on two seeds (0 and 1). Seed 2 reached only 65 % at 2k; after 2k training alone seeds differ (median 76 % at 16k).
  • S4 fails at 1–2k: the context-only control (E30 writer with 64-token reach) matches or beats e31_page on the suite cells. At length it collapses like E31's baseline memory (29 % at 16k), so the length-invariant address is what E31 adds.
  • Takeoff at 2k is stochastic (dense failed on 2 of 3 lookup seeds here); step size 5e-5 is required.
  • Training beyond 64k does not fit a 3090 without activation checkpointing; 128k is evaluation-only.
