Task table

One row per task, grouped by level (each level builds on the one before). The number is the first-letter score in percent at the training length, median over seeds; the small line is the score when the same model reads a 128k book. A solid outline is a pass (≥ 75 %) on a result that matches the task definition. Hatched cells come from an older protocol (letter badge, see the legend) and do not count yet. Hover any name or number for what it means.

Length charts: does it hold up as the book grows?

Each chart is one task (or one stage of its curriculum). The model trains at the length in the subtitle, then reads longer books with no more training. First-letter accuracy, median over seeds, only where every seed was scored that way. The dashed line is the 75 % pass mark; chance is 25 %. Dashed cards come from an older protocol.
