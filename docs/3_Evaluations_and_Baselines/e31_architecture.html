4 · Who may look at what (the exclusive read)

How to read the grid

  • Rows = tokens asking (queries) in the global read. Columns = what they may read: raw book tokens, raw question-side tokens, and the memory slots.
  • Book tokens read earlier book tokens (normal causal attention).
  • Question-side tokens read earlier question-side tokens and only the memory slots of the book. The raw book is invisible to them. That's the "exclusive" cut: the memory is the only channel.
  • Slots are built only from book tokens of their own window, with the pooling rule computed per window. That's the fix for E30's leak, where a slot could absorb later question/answer tokens.
  • The local layers after the global read also stop at QUERY, so no raw book token reaches the answer by any other route.
