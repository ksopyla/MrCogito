Round plan

Round 1 calibrates the draft protocol on Polonez, then compares. Each step waits for the gate of the one before; a failed gate changes the protocol, not the model. The state comes from the last pulled results.

Models

Frontier = the highest of T1–T5 that passes at the training length (only levels the dense model can learn count). Language = loss on held-out stories, compared with dense (within 2 % is no harm). Tokens to pass = training tokens until the lookup task first passes. Reach = the longest document where lookup still passes.

Task table

Exact-answer accuracy in percent at the training length; the small line is the score on the longest document read. A solid outline is a pass (≥ 75 % with the evidence-removed control at its floor). A struck-through red number answered without the evidence: a shortcut, not evidence. Hover a cell for the floor, the control and the depth split.

Length: does it still work on longer texts?

Every model trains at the length marked by the vertical line, then reads longer documents with no more training (more story filler, the same facts). Dashed grey: the 75 % pass mark; dotted red: the guessing floor.

Learning curves: how fast does each skill appear?

Score at the training length on checkpoints at 10, 25, 50, 75 and 100 % of the training tokens, and the held-out loss of the training mix (lower is better) — the trainability side of the comparison.

Tuning: each model's own step size

Short runs on a step-size grid, the same number for every model; the lowest held-out loss is chosen (never an exam score) and frozen in the model's recipe card before its scored run.

Task guide
