Jaegle et al., DeepMind, 2021. This page follows the papers and the released JAX in deepmind-research/perceiver — not later forks. Toy diagram uses 12 bytes and 8 latents so you can see the same slots being rewritten. ImageNet sizes are in the scale menu.

One latent array. A learned notebook of N vectors (ImageNet: 512 × 1024) is created once, then residually overwritten by every layer. Layers have weights. They do not own a private latent array. Not N new arrays per layer.

From the papers and the released encoder

      
    
        
  • One array, many writes. Z is initialized from a learned N×D parameter
          (“trainable position encoding”, truncated normal 0.02). Every cross-attend and self-attend
          returns that same index dimension. Residual: Z ← Z + Attn(LN(Z), …) then an MLP.
          Appendix C of Perceiver; PerceiverEncoder.__call__ in the JAX file.
    • 
        
  • Original Perceiver (ICML 2021) alternates cross-attend and a latent Transformer.
          Best ImageNet: 8 reads of all 50,176 pixels, 6 self-attends after each read = 48 latent blocks,
          N=512, D=1024. First cross-attend (and first latent tower) unshared; later blocks share
          corresponding weights. Functionally an RNN unrolled in depth on the same input, not in time.
          Interleaved re-reads beat “all cross-attends at the start” (78.0 vs 73.7 top-1, Table 6).
    • 
        
  • Released JAX is Perceiver IO. Encode once
          (z = self.cross_attend(z, inputs)), then
          for _ in range(num_blocks): for layer in self.self_attends: z = layer(z)
          with the six self-attend modules reused. Decode is a second cross-attend:
          output queries Q (size O) attend to Z. Classification in the first paper is not this:
          mean-pool Z, then a linear layer.
    • 
        
  • Gradients. No stop-gradient. Loss hits the decoder or the pooled vector,
          then residual skips carry gradient to every earlier write of Z, including the learned init.
          Shared modules sum gradients across unrolls (BPTT through depth). Cross-attend also
          sends gradient into the byte array’s embeddings; Fourier features themselves are not learned.
          Decoder queries are a separate parameter (or a function of the input) and get their own gradient.
